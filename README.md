# Simple To-Do List

## Description
The Simple To-Do List is a command-line application developed using Python. It helps users manage their daily tasks in an organized way. Users can add new tasks, view their task list, update existing tasks, and remove tasks when they are completed or no longer needed.

## Objective
The main objective of this project is to understand Python programming concepts and learn how to create a menu-driven application.

## Features
- Add new tasks to the list.
- View all available tasks.
- Update existing tasks.
- Remove unwanted tasks.
- Handle invalid menu choices and incorrect inputs.
- Display a simple and user-friendly menu.

## Technologies Used
- Programming Language: Python
- Editor: VS Code

## Concepts Used
This project uses Python lists, functions, loops, conditional statements, user input, and exception handling.

## How to Run
1. Open the project folder in VS Code.
2. Open the `todo.py` file.
3. Run the program using the terminal command `python3 todo.py`.
4. Select an option from the menu to manage your tasks.

## Conclusion
This project provides a basic understanding of how to develop a menu-driven application using Python. It improves programming skills, logical thinking, and knowledge of data handling using lists and functions.
